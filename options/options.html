Privacy Notice

PixelCatch

A local-only downloader for YouTube Premium and members-only videos, up to 4K, or audio. No accounts, no servers, no analytics.

What we store

  • Up to five recent download URLs in chrome.storage.local so you can re-open them quickly.
  • A download log on disk, in the OS-standard location:
    • macOS: ~/Library/Logs/com.pixelcatch.downloader.log (mode 0600)
    • Windows: %LOCALAPPDATA%\PixelCatch\downloader.log
    • Linux: ~/.local/state/pixelcatch/downloader.log

What we do not do

  • No remote servers. The extension makes no network requests of its own.
  • No Google account integration, no OAuth, no Gmail access. The extension does not request the identity permission.
  • No analytics, telemetry, or third-party scripts.
  • No reading of tab content or browsing history.

How downloads work

The popup hands a YouTube URL and a quality preset to a small Python helper on your machine via Chrome's native messaging. That helper runs yt-dlp as a subprocess and saves the resulting file to ~/Downloads (or ~/Movies / ~/Videos if you configure that). All processing happens locally.

Cookies and authentication

To download YouTube Premium quality streams and channel members-only videos, the native helper invokes yt-dlp --cookies-from-browser chrome. yt-dlp parses your default Chrome profile's cookie database to extract YouTube authentication. In the actual HTTP requests yt-dlp makes, only youtube.com cookies are sent — that's standard cookie scoping enforced by the HTTP layer.

If you'd rather not grant disk access to the full cookie store, you can export a youtube.com-only cookies.txt from any cookie-export browser extension and we can extend the host to accept that file as input instead.

Permissions

  • nativeMessaging — talk to the local yt-dlp helper.
  • storage — remember your recent downloads.
  • windows — open the popup as a free-floating panel.

User control

  • Clear recent downloads from the popup at any time.
  • Remove the extension from chrome://extensions at any time. To uninstall the helper:
    • macOS: sudo ./tools/uninstall-helper.sh (or run the helper's uninstaller from the .pkg).
    • Windows: Settings → Apps → PixelCatch Helper → Uninstall, or ./tools/uninstall-windows.ps1.
    • Linux: ./tools/uninstall-linux.sh.
