Privacy Notice

Extension Foundation

How this extension handles Google account data, Gmail access, and saved popup state.

What We Store

  • Your signed-in email and granted OAuth scopes so the popup can show your current auth state.
  • Recent YouTube links you opened from the popup.
  • The popup open counter and optional local note you save yourself.

What We Do Not Store

  • Raw Google OAuth access tokens are not persisted in chrome.storage.local.
  • Gmail message bodies are not cached by the extension unless you explicitly build your own feature on top of the current API layer.
  • No sync storage, remote analytics, or third-party tracking is included in this scaffold.

Permissions And Why

  • identity is used for Google sign-in and scope grants through Chrome Identity.
  • storage is used for local extension state like auth summaries, recent links, and popup preferences.
  • https://gmail.googleapis.com/* is used for Gmail REST API requests you trigger.
  • https://accounts.google.com/* is used for Google OAuth and token revoke flows.

Scope Model

  • gmail.readonly is used for profile, message, and label reads.
  • gmail.compose is used only for draft and send flows.
  • The scaffold intentionally avoids broader Gmail scopes such as gmail.modify unless a future feature truly needs them.

User Control

  • You can sign out from the popup to clear cached auth state and revoke the known token.
  • You can clear popup data from the popup reset action.
  • You can remove the extension entirely from chrome://extensions at any time.
